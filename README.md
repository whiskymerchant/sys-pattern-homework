`
Задание 2. Транзакции
2.1. Пользователь пополняет баланс счёта телефона, распишите пошагово, какие действия должны произойти для того, чтобы транзакция завершилась успешно. Ориентируйтесь на шесть действий.

2.1.* Какие действия должны произойти, если пополнение счёта телефона происходило бы через автоплатёж?

Приведите ответ в свободной форме.
`

2.1 
1. Пользователб инициирует запрос на пополнение:
Пользователь выбирает способ пополнения, вводит сумму, и отправляет запрос.

2. Система проверяет данные:
Проверяется наличие пользователя в системе, его текущий баланс, и корректность введенной информации (например, сумма пополнения).

3. Блокировка суммы на платёжном счёте пользователя:

После успешного списания средств, баланс телефона пользователя обновляется на соответствующую сумму.

### Задание 4

`
Задание 4. Кластеры
Необходимо производить большое количество вычислений при работе с огромным количеством данных, под эту задачу выделено 1000 машин.

На основе какого критерия будете выбирать тип СУБД и какая модель распределённых вычислений здесь справится лучше всего и почему?

Приведите ответ в свободной форме.
`
4. Нам нужна система, устойчивая к разделению. Данные должны реплицироваться на всех серверах. Насколько я понимаю, в SQL системах э
то вызывает очередь из задач, так как пока данные не пропишутся во всех таблицах, новую транзакцию система не делает. В Монго такая задача решена через Replica Set - три или более ноды, расположенные на разных серверах. Одна из них - главная. Если на одном из запросов главная нода не отвечает, переизбирается главной другая нода. Данные реплицируются после из записи на главную ноду, что помогает избежать очереди.
