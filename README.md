### Задание 2

```
Проведите сканирование Metasploitable в режимах SYN, FIN, Xmas, UDP.

Запишите сеансы сканирования в Wireshark.

Ответьте на следующие вопросы:

Чем отличаются эти режимы сканирования с точки зрения сетевого трафика?
Как отвечает сервер?
Приведите ответ в свободной форме.

```

### Решение №2


```
С точки зрения сетевого трафика:
SYN-сканирование: Отправляет SYN-пакеты для инициации соединения. Это наиболее распространенный и быстрый метод сканирования, так как только открытые порты отправляют SYN-ACK, что позволяет быстро определить доступные порты.
FIN-сканирование: Использует пакеты с установленным флагом FIN, которые предназначены для завершения соединения.
Если порт закрыт, сервер отвечает RST; если открыт, обычно нет ответа. Это поведение связано с тем, что открытые порты не должны реагировать на FIN-пакеты. По утверждению специалистов, может обойти некоторые системы обнаружения вторжений, так как данный тип трафика может не восприниматься как сканирование.
Xmas-сканирование: Устанавливает несколько флагов в TCP-заголовке (FIN, URG и PSH), что делает его похожим на Christmas tree.
Если порт закрыт, сервер отправляет RST; если открыт, обычно нет ответа. Этот метод может также сбивать с толку некоторые системы безопасности. Используется реже, но может быть полезен для обхода некоторых защитных механизмов.
UDP-сканирование: Отправляет UDP-пакеты, что отличается от TCP-соединений, так как UDP является безсоединительным.
Если порт закрыт, сервер отправляет ICMP-сообщение "порт недоступен"; если открыт, обычно нет ответа.
UDP-сканирование очень медленное и менее предсказуемым из-за разных IлCMP-ответов и возможных временных задержек.

С точки зрения ответов сервера:
SYN-сканирование: Открытые порты отвечают SYN-ACK, закрытые — RST.
FIN-сканирование: Закрытые порты отвечают RST; открытые порты не отвечают.
Xmas-сканирование: Закрытые порты отвечают RST; открытые порты не отвечают.
UDP-сканирование: Закрытые порты отвечают ICMP "недоступен"; открытые порты не отвечают.


```
